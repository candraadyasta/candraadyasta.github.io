Kebijakan Privasi: Hermes

Terakhir diperbarui: 10 November 2026 · English version below

Tentang aplikasi

Hermes adalah alat pribadi milik Candra Adyasta ("pemilik"). Aplikasi ini dipakai hanya oleh pemilik sendiri, sebagai asisten pribadi, dan tidak ditawarkan kepada pengguna lain.

Data Google yang diakses

Hermes meminta izin baca-saja ke akun Gmail milik pemilik sendiri: https://www.googleapis.com/auth/gmail.readonly. Aplikasi tidak memiliki izin untuk mengirim, mengubah, atau menghapus email.

Cara data digunakan

Email dibaca, dirangkum, dan dipilah hanya atas permintaan pemilik. Data tidak dijual, tidak dibagikan kepada pihak lain, tidak dipakai untuk iklan, dan tidak dibaca oleh manusia lain.

Teks email yang dibaca dapat dikirim ke penyedia model bahasa (AI) yang dipilih pemilik, semata-mata untuk menjawab permintaan pemilik. Pemilik tidak memakai data tersebut untuk melatih model AI. Perlakuan data oleh penyedia model pihak ketiga mengikuti kebijakan masing-masing penyedia.

Penyimpanan dan keamanan

Token akses disimpan hanya di server pribadi pemilik dengan izin berkas yang dibatasi. Tidak ada basis data pengguna lain karena aplikasi hanya memiliki satu pengguna.

Pencabutan akses

Pemilik dapat mencabut izin kapan saja di myaccount.google.com/permissions.

Kepatuhan

Penggunaan dan pengalihan informasi yang diterima dari Google API oleh Hermes mematuhi Kebijakan Data Pengguna Layanan API Google, termasuk persyaratan Limited Use.

Privacy Policy: Hermes

Last updated: 10 November 2026

About the app

Hermes is a personal tool owned and used solely by Candra Adyasta (the "owner") as a personal assistant. It is not offered to other users.

Google data accessed

Hermes requests read-only access to the owner's own Gmail account: https://www.googleapis.com/auth/gmail.readonly. The app has no permission to send, modify, or delete email.

How data is used

Email is read, summarized, and sorted only at the owner's request. Data is not sold, not shared with other parties, not used for advertising, and not read by other humans.

The text of emails that are read may be sent to a language-model (AI) provider chosen by the owner, solely to answer the owner's request. The owner does not use this data to train AI models. Handling of data by third-party model providers follows each provider's own policies.

Storage and security

The access token is stored only on the owner's private server with restricted file permissions. There is no database of other users because the app has a single user.

Revoking access

The owner can revoke access at any time at myaccount.google.com/permissions.

Compliance

Hermes's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
